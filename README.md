<h1 align="center">文 Fumi</h1>
<p align="center"><i>Documents, letters and reports. Part of 工房 Kōbō.</i></p>

Fumi is CuteClaudia's word processor, for **Windows** and **Linux**, and in the browser on
[claudiagilbert.com](https://www.claudiagilbert.com). Download the latest version from
**[Releases](https://github.com/cuteclaudia/fumi-releases/releases/latest)**.

| Platform | Download | How to install |
|---|---|---|
| Windows 10 / 11 (64-bit) | `fumi-<version>-windows-x64-setup.exe` | Run it. If Windows shows "Windows protected your PC", choose **More info → Run anyway** (or right-click the file → Properties → **Unblock**). |
| Windows, no install | `fumi-<version>-windows-x64-portable.zip` | Unzip and run `fumi.exe`. |
| Linux (any distro) | `fumi-<version>-linux-x86_64.AppImage` | Make it executable, then run it. |
| Ubuntu, Debian, Mint | `fumi-<version>-linux-x86_64.deb` | Open it with your software centre, or `sudo apt install ./fumi-*.deb`. |
| Fedora, openSUSE | `fumi-<version>-linux-x86_64.rpm` | `sudo dnf install ./fumi-*.rpm` |

Each release lists `SHA256SUMS.txt` to check your download. Every release passes a security
check first: known vulnerabilities, where its code comes from, everything it can connect to, and
a virus scan of the files. Installed copies offer new versions when they're published here.

Fumi is based on [WordCraft](https://github.com/storytold/wordcraft) by the ArtCraft Team and
the WordCraft contributors, and is licensed MIT OR Apache-2.0.
